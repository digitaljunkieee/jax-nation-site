# Jax Nation Productions, site

Static export of the Jax Nation Productions site, deployed on Render as a static site
(`jax-nation-site`, auto-deploys from the `main` branch on every push here).

This file is served as-is, no build step. To update the site, replace `index.html`
with a new export and push to `main`; Render picks up the change automatically.

Source of truth for live self-editing (the in-page admin panel with real-time publish)
is the Claude artifact this was exported from. This repo is the static mirror used for
the production domain.
